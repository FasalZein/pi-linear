# Linear extension glossary

**Operation** — A named Linear task with a fixed request and documented variables.

**Raw query** — A GraphQL document supplied directly for work outside the operation catalog.

**Allowlist** — The set of mutation actions that a mode permits.

**Read-only entry** — An extension mode that permits reads and rejects all mutations.

**Workspace** — A named Linear account and credential selection.

**Truncation metadata** — Result information that identifies omitted data and supports a narrower request or next-page request.
